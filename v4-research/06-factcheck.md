## Notes

1. HUD. All four HUD figures are vendor marketing claims, not measured outcomes. hud.ai and vendor.hud.ai serve a "Vercel Security Checkpoint" to curl (HTTP 429); the $5,000 baseline and 80/20 split were read through WebFetch of the hud.ai resources page (dated June 24, 2026). The $10k figure and 7-14 day payout come from a HUD employee's dev.to post ("Quick disclosure up front: I work with HUD AI (YC W25)"). The same dev.to post claims "In the last month alone HUD has facilitated a couple million in transactions" (unverified vendor claim). The hud.ai comparison page also states Lazarus "$10K–$100K for legacy code and up to $15K per modern repository" and a "$1,000 referral reward"; these are HUD's description of a competitor, not Turing's page.
2. Pangea. Prices are explicitly "indicative, deliberately conservative estimates ... not guaranteed payouts". The 4 screening thresholds are real but the page says "Rough thresholds, not hard gates." The 15% referral figure does not appear on either Pangea page. Payment: "Net 15 Paid within 15 days of buyer funds landing". Only fully-owned private code: "Only code you fully own — with no client claim, NDA restriction or contributor owed payment — can be offered." This rules out licensing OSS contributions to others' repos.
3. Lazarus. lazarus.turing.com is a React shell; the quoted text is in /assets/index-D1rKpMq1.js. "up to $1M" is a ceiling claim with no floor or typical value stated. Sample data in the bundle shows "Typical review time: 5-7 business days".
4. Expensify. Measured: 30 open "Help Wanted" issues; 16 closed with that label since 2026-08-25. CONTRIBUTING.md has no dollar amounts. It now describes MelvinBot, "our AI agent that posts the first proposal on an issue", reviewed first "because we are spending the money to run it", which means an AI-generated first proposal is already occupied by Expensify's own bot. There is no explicit ban on AI-assisted proposals; the rule is accountability ("You are accountable for all AI output you submit") plus the AI Etiquette "don't" list. Payment: Upwork only (fully verified profile), "no less than 7 days after the pull request is deployed to production", 50% penalty per regression, and "Contributors are eligible to be paid via Expensify 18 months after they were first assigned to a job."
5. arXiv 2602.08915 (Pinna et al., submitted 9 Feb 2026, "Comparing AI Coding Agents: A Task-Stratified Analysis of Pull Request Acceptance"). n = 7,156 PRs from the AIDev dataset, five agents. The abstract's numbers are per task type (documentation 82.1%, new features 66.1%; Codex 59.6%-88.6% across nine task categories; Claude Code docs 92.3%, features 72.6%; Cursor fixes 80.4%). The plan's "68.0% to 79.9%" range and the condition "when owner runs the agent" are not in the abstract; only the abstract was fetched, so the full text was not checked. The AIDev dataset consists of agent PRs largely opened in repos where the agent was set up by the repo's own team, so the acceptance rates are not comparable to an outsider's cold PRs; the paper does not report an outsider vs owner split in the abstract.
6. Sponsorship. 2202.05751 (Shimada et al., 2022): n = 3,697 sponsored developers, median 2 sponsors, 36% exactly one. Confirmed verbatim. 2604.03846 (Hiltz and Ghaleb, Apr 2026) contains no "60% never paid" statement; its sample is 49,148 users from a 72-hour crawl, of which 7,343 receive sponsorship.
7. Retainer comps (vendor list prices, all fetched live): fastruby.io $1,950 / $2,950 / $3,950 per month (2, 3, 4-5 days per month); railsfever.com $5,500 (up to 20k LOC) and $11,500 (up to 60k LOC) per month; gurzu.com $1,750 / $2,500 / $3,500 per month. Range across three vendors: $1,750 to $11,500 per month.
8. Bounties. All three claims confirmed. The curl program ended 2026-01-31 (primary source, Stenberg blog). IBB paused effective 27 March (primary source, HackerOne program policy, still "paused" on 2026-09-24). GitHub public tier cuts reported by The Register 2026-07-23; bounty.github.com still advertises "$10,000 or more" public / "$30,000 or more" private, consistent with the new tiers.
9. Crowdin. The "$1.13 to $1.75 per 500-key locale" figure is not on the Crowdin blog post checked (ai-translation-cost, Jan 26 2026, updated Jun 29 2026). The post prices by words, not keys: $0.45-$0.70 per 1,000 words of mobile UI depending on model. Treat the plan's figure as unverified.
10. Algora census. The "1,470 settled in 2025 vs 2 in trailing 30 days" figures are not in the cited repo. The repo measures open Bounty-labelled issues, not settlements, and is machine-authored. Treat as unverified.
11. GitHub AUP. Live text explicitly prohibits advertising "in other Users' Accounts, such as by posting monetized or excessive bulk content in issues" and using Service data "for the purposes of sending unsolicited emails to users". Cold outreach that scrapes maintainer emails from GitHub falls under the second clause.
12. Claude for OSS. Benefit is 6 months of Claude Max 20x, not cash. The "Active contributors" tier ("100 or more pull requests merged into repos you don't own in the last 12 months") matches the operator's profile (803 career merges to external repos, per BRIEF).
13. Medusa. $8M seed, July 2022 (LocalGlobe and Dawn Capital), close to $9M total including Seedcamp pre-seed. No later round found on medusajs.com or in reachable press; Crunchbase blocked (403). WebSearch quota was exhausted in this session, so no search-engine sweep was possible for a Series A.

Method limits: WebSearch budget was already exhausted (200/200) when this task ran; everything above is from direct fetches. api.github.com timed out for the gh CLI (dial tcp i/o timeout) but responded to curl with the gh auth token. hud.ai and vendor.hud.ai are behind a Vercel bot checkpoint.
